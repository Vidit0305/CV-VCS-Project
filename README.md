# Color Detector

A simple Computer Vision project that uses Python, OpenCV, and NumPy to detect basic colors from a live webcam feed.

## Features

* Real-time webcam color detection
* Detects basic colors
* Simple OpenCV image processing
* Center-region color analysis

## Technologies

* Python
* OpenCV
* NumPy

## Installation

```bash
pip install opencv-python numpy
```

## Run

```bash
python color_detector.py
```

Place a colored object inside the center rectangle.

Press:

```text
Q
```

to exit.
